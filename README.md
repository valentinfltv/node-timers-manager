# Timers Manager

A Node.js utility for managing timers with pause, resume, and remove functionality.

# Quickstart and Installation

1. Clone the repository using git:
   git clone https://github.com/valentinfltv/timers-manager.git
   cd timers-manager

2. Start app with:
   npm start
   
# Expected output

Default text: 
   Started
   t2 result: 3
   t1 fired
   
Yet it will vary depending on the inputs of index.js file
